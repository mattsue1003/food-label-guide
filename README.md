# 食品標籤這樣看｜社區衛教互動簡報（影片法）

給社區長輩的食品標籤衛教課：先一起看 3 分鐘短影音，再用這份互動簡報問答、分類、找錯，最後每個人選一件回家做得到的事。

- 簡報：https://mattsue1003.github.io/food-label-guide/
- 講師手冊（每頁帶法與答案，可列印）：https://mattsue1003.github.io/food-label-guide/#notes
- 主題：成分排序、「阿嬤看得懂」原則與添加物、反式脂肪、有效日期

## 怎麼用

- 投影：←／→ 或空白鍵換頁；`N` 講師提示；`F` 全螢幕；`T` 搶答 30 秒；右下「目錄」可跳頁
- 手機：左右滑動換頁、上下滑動看完整內容
- 第 3 頁「影片法」：點影片會跳出全螢幕播放；若顯示播放器錯誤，按「在 YouTube 開啟」
- 授課前請把第 18 頁最後一格換成當地衛生所、關懷據點的實際窗口

## 資料來源

食品安全衛生管理法第 15、22 條；衛福部食藥署（營養標示三步驟、1919 全國食安專線、食品藥物消費者知識服務網）；衛福部社區營養推廣中心；WHO 反式脂肪事實清單（2024）；Lane et al., BMJ 2024；Hall et al., Cell Metabolism 2019；IARC 2015；McCann et al., Lancet 2007；EU Regulation 1169/2011；美國農業部 FSIS；美國 CDC。
